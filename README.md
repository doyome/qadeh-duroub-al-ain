# قادح — دروب العين

لعبة قيادة وتوازن بهوية إماراتية، مستوحاة من روح Hill Climb، بمراحل من **العين**:
هيلي، الفوعة، الهير والشويب، الفقع، عين الفايضة وجبل حفيت، والطريق إلى دبي.

**العب على الجوال مباشرة:** https://doyome.github.io/qadeh-duroub-al-ain/

## المركبات
السكوتر ← الدراجة ← باترول Y60 «بو عبيد» ← باترول ربع ← باترول فتك Y61 ← باترول طويل ← لاندكروزر ← الطائرة ← الدبابة

## التحكم
- **يمين الشاشة** = بنزين، **يسار الشاشة** = فرامل ورجوع (أو الأسهم `→` `←`)
- **زر النيترو** في الأسفل بالمنتصف (أو مسافة / `↑`)
- في الهواء: البنزين يرفع المقدمة والفرامل تنزلها

## التطوير
لكل مركبة ٥ تطويرات بـ٩ مستويات: المحرك، التعليق، الإطارات، الوقود، التوازن.

## تقني
ملف HTML واحد مستقل — بدون مكتبات خارجية، يشتغل بدون إنترنت بعد أول تحميل،
ويحفظ التقدم في `localStorage`. الفيزياء مكتوبة يدويًا (هيكل جاسئ + تعليق نابض/مخمد
لكل عجلة، وقوة سحب محدودة بالتماسك).
